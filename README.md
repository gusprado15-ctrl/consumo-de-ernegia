# consumo-de-ernegia
📌 Sobre o projeto

Este projeto foi desenvolvido em Python com o objetivo de calcular o consumo mensal estimado de um aparelho elétrico.

O sistema solicita o nome do aparelho, sua potência em watts (W) e o tempo médio de uso diário em horas. Com essas informações, calcula o consumo aproximado em kWh por mês.

🐍 Tecnologias utilizadas
Python 🐍
Git
GitHub
🧮 Fórmula utilizada

O consumo mensal é calculado utilizando a seguinte fórmula:

consumoMensal = (potencia × horasDia × 30) / 1000

O resultado é apresentado em kWh/mês.

▶️ Como executar
Tenha o Python instalado no computador.
Abra a pasta do projeto no VS Code.
Abra o terminal.
Execute o comando:
python app.py
Informe:
Nome do aparelho;
Potência em watts;
Horas de uso por dia.
💡 Exemplo

Entrada:

Geladeira
100
15

Saída:

Aparelho: Geladeira
Consumo estimado: 45.0 kWh/mês
